uint64_t milvus::TelemetryConfig::heartbeat_interval_ms {10000}

Milliseconds between heartbeats, which is also the metrics window.

Each heartbeat carries the operations since the last one. The coordinator answers a telemetry query from the window before the newest, so what a caller reads is between one and two intervals old.
