◆ IsNullable()

bool milvus::FieldSchema::IsNullable ( ) const

Get the flag whether the field value is nullable.

A nullable field stores NULL when its value is omitted or explicitly NULL on insert. Primary and partition key fields cannot be nullable; vector fields with NULL cannot be filtered by IS NULL expressions.

Returns
true if the field is nullable.
