Detailed Description

Used by MilvusClientV2::Upsert()

Override mode inserts a new entity or replaces an existing one by primary key. Merge mode (WithPartialUpdate(true)) updates only the supplied fields of an existing entity.

Example
milvus::UpsertResponse response;
milvus::UpsertRequest request;
request.WithCollectionName("demo")
.AddRowData({{ "id", 1 }, { "vector", std::vector<float>{0.1f, 0.2f, 0.3f, 0.4f} }});
auto status = client->Upsert(request, response);
