◆ SetTimeoutMs()

void milvus::CreateIndexRequest::SetTimeoutMs ( int64_t  timeout_ms)

Set timeout in milliseconds.

Default value is 60000ms. Only work when Sync() is true. If the TimeoutMs is zero, the CreateIndex() will call DescribeIndex() to loading state, until the index is fully built. If the TimeoutMs is larger than zero, the CreateIndex() will break the loop after a certain of time span and return a status saying the process is timeout.

Parameters
[in]timeout_msthe timeout ms.
