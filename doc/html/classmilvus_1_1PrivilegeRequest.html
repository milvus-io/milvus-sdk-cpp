Detailed Description

Used by MilvusClientV2::GrantPrivilege() and RevokePrivilege().

The object-scoped (V1) privilege form grants a privilege on an arbitrary object, identified by its type and name. Typical object types are "Global", "Database", "Collection" and "User"; use "*" as the object name for the "Global" scope.
