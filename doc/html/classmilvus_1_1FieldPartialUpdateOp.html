Detailed Description

Describes how a field value is applied during a partial upsert.

Note
ARRAY_APPEND and ARRAY_REMOVE require Milvus server v2.6.17 or later. Older servers ignore these operations and may apply the supplied array value using REPLACE semantics.

◆ OpType

enum milvus::FieldPartialUpdateOp::OpType
strong

Operation applied to the matching field during a partial upsert.

The field named by FieldName() must also be present in the upsert payload.

Enumerator
REPLACE 

Overwrite the existing field value.

This operation is supported for all field types and is the default when no operation targets a field.

ARRAY_APPEND 

Append the supplied elements to an existing array field.

This operation is supported only for array fields. The resulting array length must not exceed the field's max_capacity.

ARRAY_REMOVE 

Remove every occurrence of each supplied element from an existing array field.

This operation is supported only for array fields. It has no effect when the existing array is empty or no supplied element matches.
