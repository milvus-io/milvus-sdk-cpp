Detailed Description

template<typename T, DataType Et>
class milvus::ArrayFieldData< T, Et >

Template class representing column-based data for an array field (supported since 2.4).


Available inheritance classes:
ArrayBoolFieldData for boolean array field
ArrayInt8FieldData for 8-bit integer array field
ArrayInt16FieldData for 16-bits integer array field
ArrayInt32FieldData for 32-bits integer array field
ArrayInt64FieldData for 64-bits integer array field
ArrayFloatFieldDataPtr for float array field
ArrayDoubleFieldData for double array field
ArrayVarCharFieldData for string array field
ArrayTextFieldData for text array field
