◆ SetResetConnection()

void milvus::UpdatePasswordRequest::SetResetConnection ( bool  reset_connection)

Set whether to reset the current connection with the new credentials after the password is updated.

When true, the client reconnects using the new password so subsequent RPCs keep working.

Note: the password is updated on the server before the reconnect is attempted. If the reconnect fails, the returned Status reports that the password was updated but the connection must be re-established manually with the new credentials.

Parameters
[in]reset_connectionthe reset connection.
