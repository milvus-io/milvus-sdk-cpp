Detailed Description

template<typename T, DataType Dt>
class milvus::FieldData< T, Dt >

Template class represents column-based data of a field.

Available inheritance classes:
BoolFieldData for boolean scalar field
Int8FieldData for 8-bit integer scalar field
Int16FieldData for 16-bits integer scalar field
Int32FieldData for 32-bits integer scalar field
Int64FieldData for 64-bits integer scalar field
FloatFieldData for float scalar field
DoubleFieldData for double scalar field
VarCharFieldData for string scalar field

Returns
the field. TextFieldData for text scalar field
JSONFieldData for JSON scalar field (supported since 2.4)
BinaryVecFieldData for float vector field
FloatVecFieldData for binary vector field
SparseFloatVecFieldData for sparse vector field
Float16VecFieldData for float16 vector field
BFloat16VecFieldData for bfloat16 vector field
